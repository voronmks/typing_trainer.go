# ⌨️ Typing Trainer (Digits) — стань мастером цифрового набора

> «Цифры — это просто, когда пальцы помнят путь»

**Typing Trainer (Digits)** — это набор консольных приложений для тренировки навыка слепого набора цифр на клавиатуре.  
Программа генерирует случайные последовательности цифр, отслеживает точность и скорость ввода, помогая довести навык до автоматизма.

## 🚀 Особенности
- 🎯 Генерация случайных цифровых последовательностей (от 1 до 9, 0).
- 📈 Реальный учёт скорости (WPM — знаков в минуту) и точности (%).
- ⏱️ Отсчёт времени и подсчёт ошибок (неправильно нажатые клавиши).
- 🎨 Цветовая подсветка правильных/неправильных символов в реальном времени.
- 🔢 Поддержка как основной, так и цифровой клавиатуры (NumPad).
- 📊 Статистика по окончании тренировки: общее время, скорость, точность, количество ошибок.
- 📝 Сохранение результатов в файл (история тренировок).
- 🎚️ Настройка длины упражнения (количество символов) и сложности (только цифры или с знаками препинания).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | `colorama`, `keyboard` (опционально) | `python typing_trainer.py`              |
| Go         | стандартная библиотека               | `go run typing_trainer.go`              |
| JavaScript | Node.js, `readline`                  | `node typing_trainer.js`                |
| Java       | стандартная библиотека               | `javac typing_trainer.java && java typing_trainer` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `rand`, `termion` (для цветов)       | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby typing_trainer.rb`                |
| PHP        | стандартная библиотека               | `php typing_trainer.php`                |

> Все программы работают в интерактивном режиме: показывают строку для ввода и принимают ввод с клавиатуры (в большинстве случаев без нажатия Enter).  
> Для упрощения в некоторых реализациях используется построчный ввод (с Enter) — это указано в комментариях.
